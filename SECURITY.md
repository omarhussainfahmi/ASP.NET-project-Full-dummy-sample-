# Reporting security issues

Please use [GitHub's private vulnerability reporting](https://github.com/omarhussainfahmi/ASP.NET-project-Full-dummy-sample-/security/advisories/new) for sensitive findings. Do not post credentials, personal records, or exploit details in public issues.

This repository is an educational sample. The public demo does not expose the unfinished person-management, database, product, or export exercises. It does not implement a production authentication system.

If you discover a published credential that you control, revoke or rotate it at its provider immediately. Removing source text or rewriting Git history does not invalidate credentials or remove third-party copies. Keep secrets in development User Secrets or a server-side secret manager.

Only the current default-branch version receives fixes. Keep your deployment runtime and dependencies patched, and do not enable the legacy exercises until their authentication, authorization, validation, persistence, and tests are complete.
